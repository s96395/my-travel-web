# Product

## 定位
Travel Web 是多人旅程管理平台。

目的：
- 規劃旅行
- 紀錄旅行
- 管理旅行

## 角色

### 建立者（Owner）
建立並管理旅程。

### 旅伴（Member）
共同編輯旅程內容。

## 首頁

Hero Card：
下一趟旅行

統計卡：
1. 去過國家
2. 年度支出
3. 旅遊類別支出
4. 累計氣瓶（僅有潛旅時顯示）

旅程列表：
- 我的旅程
- 與我共享

## 每趟旅程

- 基本資訊
- 航班
- 住宿
- 行程
- 支出
- 待辦
- 相簿
- 潛水
- 旅伴
- 設定
